# 内容发布编排

> 业务环节：**营销推广** ｜ 安全分级：**L4** ｜ 台账状态：`planned` ｜ 优先级：P1

## 何时使用

种草笔记、短视频脚本、直播预告等多平台内容编排与发布前检查时使用。

## 输入契约

- `campaign`：活动主题与目标
- `platforms`：目标平台列表
- `assets`：可用素材（图/视频/卖点）

## 工作流

1. 按平台调性改写同一卖点为差异化文案（避免一稿多发）。
2. 生成发布清单：平台 / 文案 / 素材 / 发布时间。
3. 逐条做合规检查（极限词、医疗功效、对比贬低）。
4. 输出待审清单，发布动作必须经人工批准。

## 输出契约

```json
{ "plan": [{ "platform": "xiaohongshu", "copy": "", "assets": [], "publishAt": "", "compliance": { "passed": true, "hits": [] } }] }
```

## 验收门禁

- 合规检查未通过的条目不得进入发布队列。
- 含价格/优惠的文案必须引用活动配置，禁止手写价格。

## 失败样本（Golden Corpus）

- 极限词命中 → 直接退回改写，不得仅提示。
- 平台接口变更导致字段不匹配 → 输出字段差异报告，不猜测字段。

## 依赖能力

- `skills/promo-planning`
- `adapters/mcp-cn-commerce`

## 边界

- 本 Skill 只产出**结论与建议**；L2 及以上写动作必须经人工确认后由对应 MCP 执行。
- 所有事实性输出必须可回溯到数据源；无来源时输出「需人工确认」，不得臆造。
- 定时类用法必须带 `runKey`（日期 + 任务名）保证幂等。
